# TBD — Name Not Found

[English](README.md) | **한국어**

> `404 — Name Not Found. Let's make one!`

사람, 장소, 가게, 아이템 이름을 지어 주는 실리태번 확장이에요.

AI는 어떤 모델을 써도 비슷비슷한 이름을 내놓는 버릇이 있어요. TBD는 무작위를 AI에게 맡기지 않고 직접 굴려요. 이름마다 따로 씨앗(첫 글자, 음절 수, 끝소리, 느낌, 무작위 단어 하나)을 줘서, 한 번에 뽑은 이름들이 뻔한 쪽으로 몰리지 않게 해요(한 소리가 거의 모든 이름에 들어가지 않게도 부탁해요). 한국어 설명은 한글 낱말로만 써 달라고 해요(일부 모델이 한자를 섞어서). AI가 자주 쓰는 이름과 이미 받았던 이름은 알아서 피해요.

## 기능 (v0.2.24)

- 마법봉 메뉴(✨) → **TBD: 이름 짓기**로 열어요
- **만드는 방식: AI / Archive / Archive + AI** (사람·장소). **Archive**는 확장 안에 넣어 둔 이름 조각으로 이름을 만들어요. AI를 안 써서 공짜예요. 뿌리(라틴, 옛 영어, 노르만·프랑스, 게르만, 켈트, 북유럽, 고대 그리스, 슬라브)를 고르고, 사람이면 이름 종류도 골라요: 일반 인명, 귀족 가문, 수도원·성인, 왕족·군주(`King Godwald the Good`, `Rex Marus II`, `Duc Thibaud le Hardi`, `Herzogin Helmgard die Große`: 뿌리마다 군주 칭호 여러 개, 노르만·게르만 별칭은 그 나라 말로), 전사·별칭(`Thorgeir Ironhand`), 학자(라틴식, `Ethelwinus Ashfordensis`). 일반 인명의 성은 아버지 이름 / 출신 지명 / 사는 곳(`Atwood` = 숲 곁에) / 직업(`Thatcher`) / 생김새·별명(`Armstrong`) 다섯 갈래에서 나오고, fragments 줄에 어느 갈래인지 나와요. 장소엔 가끔 덧붙임 말(`Great …`, `…-on-Sea`, `Ober…`)이나 성인 이름(`St. Edwin's`, `Kilbranan`)이 붙어요. 조각 뜻은 이름·지명 자료로 확인했어요. 장소는 종류 칸(숲, 호수, 산…)을 따라가요. 이름마다 **fragments** 줄에 조각과 뜻이 나와요(예: `Ash 물푸레나무 + ford 여울 · 옛 영어`). 뿌리와 이름 종류는 바꾸는 동안 전부 꺼도 돼요(그대로 찾으면 하나 골라 달라고 해요). 성에는 이름에 쓴 조각이 다시 안 들어가요(그리스 -os 조각도). 두 조각이 만나는 곳에선 같은 소리·같은 뜻이 겹치지 않고(`Gorogorod`, 요새+요새 같은 것), 장소가 꾸미는 말 두 개로만 되지 않고, 장소 종류를 고르면 그 종류 조각이 꼭 하나 들어가요. 슬라브 덧붙임 말은 지명에 맞춰 바뀌고(`Velika Reka`, `Gornje Selo`), 긴 슬라브·그리스 아버지 이름 성은 앞조각만 쓰고(`Aristides`), -reka 지명 성은 `-recki`가 되고, 학자 라틴식에는 악센트가 없고, 노르만 이름은 게르만 이름의 프랑스 꼴이나 프랑스식 애칭 꼴이고(`Thibaud`, `Aubert`, `Clairette` — `Blancault`처럼 프랑스어 낱말에 게르만 끝이 붙지 않음), 켈트 이름은 이름부터 성·출신지까지 한 말만 써요(웨일스 `Cadog ap Tegwal`, `Llan…` / 게일 `Fergus MacBrigan`, `Kil…` / 웨일스 딸은 `ferch …`), 라틴 학자는 라틴 낱말 성을 그대로 써요(`Agricola`, `Pictor`와 `Pictorius`가 반반쯤). 한 번에 뽑은 목록엔 같은 별칭이 두 번 안 나오고(남은 게 있을 때), 같은 앞조각과 장소·이름·성의 끝도 몰리지 않고(`Chryso…`, `…magus`, `…mila` 네 번 같은 것), 같은 성이 두 번 안 나오고, 한 지명에 "큰"과 "작은"이 같이 안 붙고, 군주 서수는 주로 작은 숫자예요(II·III, IX는 드물게). 뿌리를 여러 개 고르면 **Split**(이름마다 뿌리 하나씩 돌아가며, 기본)이나 **Merge**(이름마다 서로 다른 뿌리 두 개를 섞음: 이름은 앞조각을 한 뿌리에서, 끝조각을 다른 뿌리에서 / 장소는 앞말과 꼬리를 각각 / 성·칭호·별칭은 둘 중 한 뿌리 방식)를 골라요. 그러면 fragments 줄에 조각마다 어느 뿌리인지 나오고(예: `Pont 다리 (라틴) + rigg 산등성이 (북유럽) · 라틴 + 북유럽`), 🔄도 같은 두 뿌리로 다시 뽑아요. 길이·소리 느낌·꼭 들어갈 글자는 그대로 적용되고, 분위기·비슷하게·실제 이름 칸은 Archive에선 숨어요. 🔄와 조각 다시 뽑기는 Archive로, ✨는 AI로 해요. Archive 이름엔 아직 읽는 법이 없어요
- **Archive + AI** (만드는 방식 세 번째 버튼): Archive가 이름을 만들고, AI 요청 한 번으로 소리를 살짝 다듬어요(한두 글자나 조각이 이어지는 자리, 첫 글자와 끝 글자는 늘 그대로). 읽는 법과 느낌 설명도 붙여요. 뜻은 늘 Archive 자료에서만 나오고 AI가 지어내지 않아요. 칭호·앞말·별칭·고정한 성은 안 건드려요. AI가 실제로 바꾼 이름엔 **AI 다듬음** 표시가 붙고 fragments 줄 끝에 `원래: …`가 나와요. 그대로 둔 이름은 **ARCHIVE**로 남고, AI가 쓴 읽는 법과 설명만 붙어요. AI가 실패해도 조각 이름은 그대로 보여요. 🔄와 조각 다시 뽑기도 다듬어서 나오고, ✨는 예전과 같아요
- **한국 (Archive 뿌리)**: Archive 뿌리에서 **한국**을 고르면 한국 사람 이름을 만들어요. 성 한 글자 + 이름 두 글자 한자이고, 한자마다 소리와 뜻이 붙어요(예: `김서윤 金瑞允 · Kim Seo-yun`, fragments `瑞 서 상서로운 + 允 윤 진실한`). 한국어 화면에선 한글로, 영어 화면에선 로마자(국어의 로마자 표기법, 성은 Kim·Lee·Park 같은 흔한 표기)로 크게 나오고, 나머지 두 가지는 아래에 있어서 누르면 복사돼요. 한자는 성별과 자주 쓰는 자리(첫 글자·끝 글자)에 맞게 고르고, 한 목록에서 같은 소리가 몰리지 않고, 평범한 낱말이 되는 이름(경우, 우유 같은 것)은 빼요. 지금은 일반 인명만(미들네임·특수한 이름 없음), 한국 지명은 아직 없고, 한국을 켜면 Merge는 Split로 뽑고(안내가 떠요), Archive + AI에서도 한국 이름은 그대로 둬요. 🔎는 한글로 한국어 위키백과를 찾아요
- **검사용 복사**: 상태 줄 옆 작은 버튼을 누르면 지금 보이는 이름 전부가 글로 복사돼요. 만든 조건(같은 조건은 한 번만), 이름마다 표시·성별·이름 종류, AI 이름은 이름마다 받은 씨앗(뿌리·첫 글자·음절 수·성 종류), Archive 이름은 조각마다 fragments·뜻(영어)·뿌리까지 들어가요. 잘 모르는 외국어 이름을 캡처 없이 대화창에 붙여넣어 검사받을 때 써요
- **Roster(명부)**: 직접 모은 이름 명부. **Roster** 탭에서 명부를 만들고, 찾아 둔 이름(귀족 명부, 옛 지명…)을 한 줄에 하나씩 붙여넣어요. `이름 | 메모`로 메모를 달 수 있고, 표에서 복사한 줄도 돼요. 명부마다 사람용·장소용을 정하고, 사람 명부는 전체 이름 / 이름만 / 성만 중에서 골라요. 그다음 **만드는 방식: Roster**에서 명부를 골라 **그대로**(무작위로 뽑음, AI 안 씀)나 **변형 (AI)**(뽑은 이름을 AI가 같은 말의 새 이름으로 바꿈, 뽑힌 이름만 보냄)로 써요. "이름만" 명부와 "성만" 명부를 같이 고르면 붙여서 전체 이름으로 줘요. 명부는 실리태번 설정에만 저장되고(이름 2,000개까지), 내보내기·불러오기가 돼요(.json, 또는 한 줄에 이름 하나인 .txt / .csv). 기본으로 든 Archive와는 따로라서 둘이 섞이지 않아요
- **Found ⭐**: 이름 옆 ☆를 누르면 모아 둬요. 위쪽 **Found** 탭에서 모은 이름을 최근 것부터 보고, 대상(사람·장소…)별로 거르고, 복사하거나 뺄 수 있어요. 읽는 법·설명·애칭·표시·fragments도 같이 남아요. Found에 넣은 이름은 새 결과에 다시 안 나와요. **내보내기**로 파일로 저장하고(백업·옮기기), **불러오기**로 그 파일에서 이름을 더해요(이미 있는 이름은 건너뜀). 최대 500개, 실리태번 설정에 저장돼요
- 조건: 대상(사람 / 장소 / 가게 / 아이템 / 기타), 분위기(목록에서 고르거나 직접 쓰기), 성별 느낌, 길이. 덜 쓰는 조건(소리 느낌, 꼭 들어갈 글자, 비슷하게, 실제 이름, 낱말 이름)은 **조건 더 보기**로 접혀 있고, 접혀 있어도 바꿔 둔 것은 그 줄에 보여요
- "비슷하게" 칸: 이름이나 단어(Elric, Aldous)를 쓰면 소리가 닮은 이름(리듬이 비슷하고, 이름마다 앞소리·모음·끝소리 등 닮는 부분이 달라요. 분위기보다 우선), 또는 느낌이 닮은 이름(같은 문화권·시대, 다른 소리)을 지어요. 쓴 단어 그대로는 안 나와요. 전체 이름이면 이름 조각에 적용돼요
- 장소·가게·아이템은 종류도 골라요. 어느 세계에도 맞는 일상 분류예요(거리·구역, 역·공항, 수리점, 꽃집, 탈것, 약, 전자기기… 또는 직접 쓰기)
- 사람 이름을 나눠 뽑아요: 이름 구성(이름·미들네임·성)과 특수한 이름(직함·존칭, 귀족 표시, 출신지, 아버지 이름 성, 별명·칭호, 세례명·수도명, 코드네임, 가명·예명)을 골라요. 성은 분위기에 맞게 나오고, "성 고정"으로 한 가족 이름을 지을 수 있어요. 특수한 이름은 한 줄로 접히고, 켠 것이 보여요. 이름만 켜면 성은 붙지 않아요
- 전체 이름 아래에 조각이 따로 나와요. 누르면 그 조각만 복사, 🔄로 그 조각만 다시 뽑기
- 장소·가게·아이템에 "자세히" 칸이 있어요(예: 반쯤 부서진 군용 드론). 안 써도 돼요. "기타"는 무엇의 이름인지 직접 써요. 종류를 "상관없음"으로 두면 자세히 칸 글이 그 물건 자체가 돼요("빵"이면 빵 이름. 빵집이나 빵 바구니 이름이 아님)
- 분위기가 먼저예요: 무작위 단어를 분위기별로 고르고(한 번에 같은 단어 두 번 안 씀), 장소는 사람 이름처럼 들리지 않게 하고 진짜 낱말도 써요(Blackwater, Salt Flats). 사전 낱말 하나만 덩그러니 쓰는 건 피해요
- 분위기: 판타지, 중세, SF, 현대, 고딕, 포근한, 신화·전설, 판타지 게임, 러브크래프트풍, 기묘한, 또는 직접 쓰기. 러브크래프트풍은 사람까지 크툴루식으로 이질적인 이름이 나오고, 실제 이름 쪽을 고르면 원작 속 낡은 마을 사람 이름이 나와요. 기묘한은 마음껏 이상해도 소리 내어 읽을 수는 있게 해요
- 게임에서 흔한 이름(Shadowfang)은 작게 "AI 단골", 러브크래프트 원작에 나오는 이름(Innsmouth)은 "원작"으로 표시해요. 둘 다 숨기지 않고 표시만 해요
- 사람 이름도 분위기를 따라가요: 분위기마다 끝소리·규칙·예시가 달라서, 판타지가 아닌 분위기에서 판타지 같은 이름이 나오지 않게 해요
- 직접 쓴 글이 먼저예요: 분위기나 자세히 칸을 직접 쓰면 무작위 단어를 넣지 않고, 무작위 단어 속 물건이 이름에 엉뚱하게 끼어들지 않게 해요
- 평범한 영어 낱말인 이름(Wren, Ox)은 숨기지 않고 "낱말: 굴뚝새"처럼 작게 표시해요. 그대로 쓰거나 ✨로 바꿔 보면 돼요. 설정에서 아예 빼게 할 수도 있어요. 이름·미들네임과 한 단어짜리 사람·장소·기타 이름만, 똑같을 때만 표시해요(Wrenna는 통과)
- **뿌리** 칸(AI, 사람·장소, "조건 더 보기" 안): 상관없음(기본, 지금과 같음) 또는 Archive와 같은 뿌리를 하나 이상 골라요. 그러면 AI가 그 뿌리의 말 조각으로 새 이름을 만들고(이미 있는 이름이나 다른 나라 낱말은 안 씀, 라틴은 이탈리아어·프랑스어 꼴 말고 고전 라틴 꼴로, 길이가 상관없음이면 사람 이름은 두 음절 이상이라 투박한 한 음절 이름이 안 나옴, 성은 이름마다 장소·아버지 이름·생김새·직업과, Merge면 두 뿌리 중 어느 말로 지을지를 돌아가며 정해 줘서 한쪽으로 몰리거나 영어로 빠지지 않게. 켈트는 이름마다 웨일스어·아일랜드어·스코틀랜드 게일어 중 하나로 정해 줘서 섞이거나 영어·스코트어로 빠지지 않게, 슬라브 성은 여자면 여성형으로), 분위기는 철자와 느낌만 맞춰요. 이때는 무작위 영감 단어를 안 줘서, 그 물건이 이름에 그대로 들어가지 않아요. 여러 개 고르면 Split은 이름마다 돌아가며 하나씩, Merge는 한 이름에 뿌리 두 개를 섞어 달라고 해요. 이름마다 어느 뿌리가 앞, 어느 뿌리가 끝인지 돌아가며 정해 줘서 끝이 한 뿌리로 몰리지 않아요(Archive와 AI의 Split/Merge는 따로 저장돼요). AI가 이미 아는 내용이라 검색 기능은 필요 없어요. 다만 뜻은 틀릴 수 있어서 설명엔 느낌만 쓰고 뜻이나 유래는 단정하지 않아요(정확한 뜻은 Archive로). 다른 칸과 반대 말을 하면 하나만 AI에게 보내요: "비슷하게"에 글이 있으면 그 단어를 따르고, 러브크래프트풍 지어낸 사람 이름은 이질적인 이름 그대로예요. 이때 접힌 줄엔 뿌리가 줄 그어져 보여요
- **실제 이름** 칸(사람): 지어낸 이름만(기본) / 실제 이름 비슷하게 / 실제 이름도 섞기 / 실제 이름만. 신화·전설에선 실제 신화 속 이름, 기묘한에선 실제로 있지만 드물고 이상한 이름, 판타지 게임에선 실제 이름을 게임 주인공처럼 써요. 이름·미들네임·성에 적용되고, 코드네임 같은 특수한 이름은 지어내요. 성 고정은 그대로예요. AI가 실제 이름이라고 한 건 작게 "실제"로 표시해요(AI 판단이라 틀릴 수 있어요. 🔎로 확인해 보세요). 실제 이름을 고르면 낱말이기도 한 실제 이름(Rose)은 낱말을 빼는 설정이어도 남고, "실제 이름만"에선 AI 단골 이름(Luna)도 빼지 않고 표시만 해요
- **실제 지명** 칸(장소, AI): 지어낸 지명만(기본) / 실제 지명 비슷하게 / 실제 지명도 섞기 / 실제 지명만. 사람의 실제 이름 칸과 따로 저장돼요. 기본값은 예전과 똑같고, 다른 걸 고르면 실제 지명을 써요(신화·전설에선 전설 속 장소, 러브크래프트풍에선 낡은 뉴잉글랜드 바닷가 마을, SF에선 식민지·정거장에 빌려 쓴 실제 지구 지명). AI가 실제라고 한 건 "실제"로 표시해요
- **낱말 이름** 칸(사람, AI): 피하기(기본, 지금까지처럼 지어낸 이름) / 섞기(3개 중 1개쯤) / 위주로(거의 다). 낱말 이름은 아무 나라 말(영어도)의 예쁜 진짜 낱말을 그대로 쓰거나 살짝 바꿔서 만들어요. 뿌리를 켜면 그 뿌리의 말에서 골라요. 이름마다 `낱말: 별 · 라틴어`처럼 뜻과 언어가 작게 표시돼요(AI 추정). 이름에만 적용되고, 성은 원래 조건을 따라요. "비슷하게" 단어나 "실제 이름만"이 있으면 그쪽이 이기고 칸에 "지금은 안 써요"가 떠요. 낱말 이름은 낱말을 빼는 설정이어도 안 빠지고, "위주로"에선 AI 단골 이름(Luna)도 빼지 않고 표시만 해요
- **애칭 보기**(설정, 기본 꺼짐): 사람 이름 아래에 애칭 2~3개가 같이 나와요(이름 그대로는 빼요). 누르면 복사돼요
- 이름 옆에 읽는 법: 한국어 화면에선 한글로, 영어 화면에선 강세 표기로(예: KWIL-uh). 끌 수 있어요
- 한 번에 1~30개 (기본 5개), 이름마다 짧은 설명
- 이름 복사
- **이름 확인**(이름 옆 🔎): 위키백과에서 똑같은 이름의 문서가 있는지 찾고, 구글 검색 링크도 줘요. 전체 이름이면 전체와 이름·미들네임·성을 하나씩 찾아요. 고정한 성과 특수한 이름은 안 찾아요. 한국어 화면이면 한글 읽는 법으로 한국어 위키백과도 찾아요. "이름 문서"(그 이름 자체를 설명하는 문서)는 실제로 쓰는 이름이라는 뜻이에요. **AI에게도 묻기**를 누르면 유명한 브랜드·캐릭터·지명과 겹치는지, 다른 언어에서 나쁜 뜻이 있는지 물어봐요("AI 추정" 표시). 이름은 🔎를 누를 때만(또는 자동 확인을 켰을 때) 위키백과로 보내져요. 법적인 상표 확인은 아니에요
- 소리 다듬기(이름 옆 ✨ 버튼): 더 부드럽게, 단단하게, 날카롭게, 밝게, 어둡게, 짧게, 길게. 원래 이름 아래에 변형 3개가 나오고, 변형도 다시 다듬을 수 있어요
- 이름 하나만 다시 뽑기(이름 옆 🔄): 변형은 만들어진 방식 그대로, 처음 뽑은 이름은 그때의 검색 조건으로 새로 뽑아요
- 소리 묶음은 음운학을 따라요: 부드럽게 = l, r, m, n, w, y와 모음 / 단단하게 = k, t, p, d, g, b / 날카롭게 = s, z, x, f, v, sh, th / 밝게 = i, e / 어둡게 = o, u, a. AI는 글자가 아니라 소리로 판단해요
- 지금 쓰는 API나 따로 고른 연결 프로필로 요청
- 답이 중간에 잘려도 끝까지 쓴 이름은 살리고, 상태 줄에서 최대 응답 토큰을 늘리라고 알려 줘요. 생각하는 모델이 생각하다 토큰을 다 쓰거나 빈 답이 오면, 무엇을 해 보면 되는지 알려 줘요
- 답을 못 쓰게 되면 **받은 답 보기**로 AI가 실제로 보낸 글을 볼 수 있어요
- 피할 이름: AI가 자주 쓰는 이름 + 직접 적은 목록 + 전에 받은 이름 (끄거나 비울 수 있어요). 설정에서 지난 이름을 보고 하나씩 지울 수도 있어요. AI에게는 AI 단골 이름과 직접 적은 목록만 보내고, 지난 이름·Found 이름은 받은 뒤에 걸러서 AI가 덜 헤매요. 성은 여러 사람이 같이 쓰니까, 전에 나온 성이라는 이유만으로 새 이름을 빼진 않아요(직접 적은 목록에 있는 성은 빼요)
- 테마: 실리태번 따라가기(기본), 터미널, 블루스크린, 커널 패닉, 유리(어둡게), 유리(맑게), 옛날 오류창, 경고 테이프, 네온 글리치
- 창을 스크롤해도 맨 위 줄(⚙ ✕)은 그 자리에 있어요
- 움직이는 효과는 끌 수 있어요. 휴대폰에선 가볍게 보여 주고, "동작 줄이기" 설정도 따라요
- 영어 / 한국어 화면

## 설정

확장 패널에서 **TBD — Name Not Found**를 찾거나, 창의 ✕ 옆 ⚙를 누르면 돼요. 두 곳은 같은 설정이고 서로 바로 맞춰져요.

| 설정 | 하는 일 |
|---|---|
| 언어 | 실리태번 따라가기, 영어, 한국어 |
| 연결 프로필 | 어떤 API에 물어볼지. 비워 두면 지금 쓰는 API |
| 생각 정도 | 생각하는 모델용. 기본은 아무것도 안 보내요. 생각하는 모델이 빈 답을 보내거나 느리면 "낮게"로 두세요(토큰을 생각에 다 쓸 수 있어요). Custom(OpenAI 호환) 연결에선 실리태번이 OpenAI 모델에만 보내니, 서비스 전용 연결이나 생각 안 하는 모델을 쓰세요. "최소"는 생각을 아예 하지 말라는 뜻이라, 항상 생각하는 모델은 거절할 수 있어요. 그럴 땐 "낮게"로 두세요. 설정이 안 먹히는 것 같으면 다른 확장이 요청을 가로채고 있을 수 있어요 |
| 연결 프로필의 프리셋도 같이 보내기 | 기본 꺼짐. 롤플레이 프리셋을 같이 보내면 빈 답이나 롤플레이로 답할 수 있어요. 모델에 꼭 필요할 때만 켜세요 |
| 한 번에 뽑을 이름 수 | 1~30 |
| 최대 응답 토큰 | 기본 2000, 많이 뽑을 땐 자동으로 늘어나요. 최대 65000까지 넣을 수 있어요. 생각하는 모델은 더 필요할 수 있지만, 너무 높으면 오래 생각할 수 있어요. 답이 잘리지 않을 만큼만 넉넉히 두세요. 아주 작은 로컬 모델이면 줄이세요 |
| 테마 / 움직이는 효과 | 창 모양 |
| 이름 읽는 법 보기 | 이름 옆에 읽는 법 표시 (기본 켜짐) |
| 애칭 보기 | 사람 이름 아래 애칭 2~3개 (기본 꺼짐, 토큰을 조금 더 써요) |
| 새 이름 자동으로 확인 | 이름이 나올 때마다 위키백과에서 찾아, 같은 이름의 문서가 있을 때만 ⚠를 보여 줘요 (기본 꺼짐) |
| 평범한 영어 낱말인 이름 | 표시만 하기(기본) 또는 아예 빼기 |
| 이미 나온 이름은 피하기 | 최근 결과를 기억해서 다시 안 나오게 해요 |
| 항상 피할 이름 | 직접 적는 목록. 쉼표나 줄바꿈으로 구분 |
